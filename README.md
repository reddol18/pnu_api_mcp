# pnu_api_mcp

주소나 PNU(필지고유번호)를 넣으면 **건물과 필지의 관계**(건물 하나가 여러 필지에 걸쳤는지, 필지 하나에 건물이 여러 동인지)를 건축물대장과 공간 데이터로 판정하는 도구. Claude에서 쓰는 MCP 서버와 웹 조회 화면으로 제공한다.

- 웹: **https://pnu.reddol18.pe.kr** — 주소·PNU를 넣으면 판정 결과와 지도(필지 경계·건물 외곽선)를 보여 준다
- 설계: [docs/design.md](docs/design.md)
- 상태: 1단계 완료 — MCP 도구 5개, 웹 배포(AWS) (2026-11-25)

## MCP 도구

| 도구                | 입력                                  | 하는 일                                                         |
| ------------------- | ------------------------------------- | --------------------------------------------------------------- |
| `classify_relation` | 주소·PNU·건물관리번호·건물명 무엇이든 | 출발점을 정해 관계를 판정. 한 줄 요약 + 대장·공간 근거 + 불일치 |
| `parcel_buildings`  | PNU 또는 지번주소                     | 이 필지의 건물들, 그 건물들이 걸친 다른 필지                    |
| `building_parcels`  | 도로명주소·건물관리번호·건물명        | 이 건물이 걸친 필지들 (대표·부속지번 + 외곽선 겹침 비율)        |
| `resolve_address`   | 주소·건물명                           | 후보 목록. 지번주소면 법정동코드 표로 만든 PNU 후보도           |
| `decode_pnu`        | PNU                                   | PNU 해독. 외부 호출·키 없음                                     |

관계 표기는 **건물 수 : 필지 수**(`1:1`, `1:N`, `N:1`, `N:M`). 대장 기준(표제부·부속지번)과 공간 기준(건물 외곽선 겹침)을 따로 판정하고, 둘이 다르면 `discrepancies`에 적는다. 예) `남산공원길 105` → 대장은 산1-3·산1-11(1:N)인데 YTN서울타워 외곽선은 산1-11 위에만 있다(1:1) — 주소의 대표지번 위에 건물이 없다.

공공 API가 잠깐 응답하지 않으면 결과의 `incomplete`에 빠진 자료와 "잠시 후 다시 물어보면 된다"는 안내가 붙는다.

### 필요한 키 (본인 키, 무료)

`.env.example`을 `.env`로 복사해 채운다: `JUSO_KEY`(도로명주소 검색 API), `DATA_GO_KR_KEY`(건축HUB 건축물대장정보), `VWORLD_KEY` + `VWORLD_DOMAIN`(브이월드 2D데이터, 키 발급 때 등록한 서비스 URL — 서버 호출에 꼭 필요).

### `decode_pnu` 예

입력 `1126010200101260039`의 결과(일부):

```json
{
  "sido": "서울특별시",
  "sigungu": "중랑구",
  "eupmyeondong": "상봉동",
  "ri": null,
  "mountain": false,
  "bonbun": 126,
  "bubun": 39,
  "jibunAddress": "서울특별시 중랑구 상봉동 126-39",
  "ledgerKey": { "sigunguCd": "11260", "bjdongCd": "10200", "platGbCd": "0", "bun": "0126", "ji": "0039" }
}
```

`ledgerKey`는 건축물대장 API 조회 키다. 필지구분 값이 PNU(1=일반, 2=산)와 달리 `platGbCd`(0=대지, 1=산)라서 따로 돌려준다.

법정동코드는 2022년 4월판 스냅숏이다(`packages/core/data/bjdong_codes.tsv`). 최신판으로 교체 예정.

### 판정 예

| 입력                                 | 대장 기준                        | 공간 기준(외곽선 겹침)          | 비고                                     |
| ------------------------------------ | -------------------------------- | ------------------------------- | ---------------------------------------- |
| `남산공원길 105` (YTN서울타워)       | 1:N — 산1-3(대표) + 산1-11(부속) | 1:1 — 산1-11 위에 100%          | 불일치: 주소의 대표지번 위에 건물이 없다 |
| `낭성면 행정복지센터` (이목리 120-3) | 1:N — 120-3 + 부속 34-6·262-3    | 1:N — 78.7% · 17.0% · 4.3%      | 두 근거 일치                             |
| `서울특별시 중랑구 상봉동 126-39`    | 없음                             | 없음 — 연속지적도에 필지가 없다 | 지금은 없는 지번일 수 있다(합필 등)      |

## 알려진 한계

- 집합건물은 동(표제부) 단위까지. 전유부(호)는 다루지 않는다.
- 공간 기준의 건물은 도로명주소 건물 레이어라서 도로명주소가 없는 부속건축물은 빠진다.
- 건축HUB에는 "이 필지를 부속지번으로 쓰는 건물"을 거꾸로 찾는 조회가 없다 → 필지 출발일 때 그런 건물은 공간 기준에만 나온다.
- 경계 접촉(1% 미만)·작은 겹침(5% 미만) 기준은 지금까지 모은 사례로 정한 임시값이다.
- 건축HUB가 간헐적으로 약 5초 뒤 503을 준다 → 짧게 재시도하고, 계속 실패하면 대장 결과 없이 `incomplete` 안내로 답한다.

## 웹 (https://pnu.reddol18.pe.kr)

- Next.js 16 + MapLibre GL. 공공 API 키는 서버(Lambda)에서만 쓴다. 배경지도는 CloudFront가 브이월드 타일을 받아 캐시한다(키를 브라우저에 내보내지 않음).
- 지도: 출발 필지(파랑), 건물이 걸친 필지(회색), 대장에만 있는 필지(빨강 점선), 건물 외곽선(주황).
- 조회 제한 IP당 10분 30회, 결과 캐시 7일.
- 배포: AWS Lambda(Web Adapter) + CloudFront, CloudFormation 스택 하나(`infra/template.yaml`). zip은 GitHub Actions가 만들고 배포는 `node infra/deploy.mjs`. 사용량 폭주 차단 스위치, CloudFront 문지기 함수(허용 경로·메서드만 통과, 의심 IP 자동 차단, 주요 검색·AI 크롤러만 페이지 허용) 포함. 운영 절차는 `CLAUDE.md`.

## 개발

Node 22 이상, pnpm.

```bash
pnpm install
pnpm lint
pnpm turbo run typecheck test build
```

웹 로컬 실행: `pnpm --filter @pnu/web dev`(루트 `.env`를 읽는다).

Claude Code에 로컬 빌드로 연결(npm 배포는 아직 없다): 저장소 루트의 `.mcp.json`이 `node --env-file-if-exists=.env packages/mcp/dist/cli.js`를 띄운다(빌드 후 이 폴더에서 Claude Code를 열고 `/mcp`로 승인). 다른 곳에서 쓰려면:

```bash
claude mcp add pnu -e JUSO_KEY=... -e DATA_GO_KR_KEY=... -e VWORLD_KEY=... -e VWORLD_DOMAIN=... -- node <이 저장소>/packages/mcp/dist/cli.js
```
